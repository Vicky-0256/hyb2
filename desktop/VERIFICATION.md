## Scope limits

The file/project/task native IPC implementation is still a later milestone.
The adapter currently falls back to browser downloads, while the Python
runtime and task runner are runnable development prototypes. Neither the
schema nor capability detection alone demonstrates that a complete native
analysis workflow is installed. The desktop UI's CPLfold capacity bypass is
capability-gated: it activates only when the Tauri runtime advertises a
validated `cplfoldNative` capability backed by bundled Python/NumPy/CPLfold;
otherwise the existing browser measurement path remains active.
The intended sidecar versions and startup checks are recorded in
`runtime/bundle-manifest.json`; the sidecar itself is not yet included in this
first shell build. The manifest now includes Numba JIT as an acceleration
dependency; the first native run must record JIT compilation and cache status
in task provenance.
